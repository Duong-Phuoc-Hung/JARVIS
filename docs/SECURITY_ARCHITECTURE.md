# JARVIS Security Architecture & Threat Model

This document specifies the concrete security boundaries, threat mitigations, and execution isolation layers in the **JARVIS** platform (Windows 10/11 x64).

---

## 1. Security Boundary Matrix

| Vector / Asset | Primary Security Boundary (OS Kernel) | Defense-in-Depth (Application Layer) | Status |
|---|---|---|:---:|
| **Process Execution & Child Spawning** | **Windows Job Object** (`ActiveProcessLimit = 1`, `JobMemoryLimit = 256MB`, hard timeout). Windows kernel denies `CreateProcessW` with `WinError 1816`. | AST Code Visitor blocks `ast.Import` on `subprocess`, `os.system`. | ✅ **KERNEL ENFORCED** |
| **Filesystem Write & Workspace Tampering** | **Windows Mandatory Integrity Control (MIC)**: Token Integrity Level set to `LOW (S-1-16-4096)`. Throws `[Errno 13] Permission denied` on Medium/High folders. | Closure-Free Slot-based Guard (`_ScopedBuiltinOpenGuard`, `_ScopedIOOpenGuard`, `_ScopedOSOpenGuard`). | ✅ **KERNEL ENFORCED** |
| **Secrets & Credential Access** | **Environment Block Sanitization**: Child process environment block is scrubbed before spawn. Secrets are 100% stripped. | Directory Allowlist blocks reading outside `_SANDBOX_ROOT_DIR`. | ✅ **KERNEL / MEMORY ENFORCED** |
| **Network Communication & Exfiltration** | **Application-Layer Deny-by-Default (Active)**: Two-tier `sys.modules` Poisoning + `sys.meta_path[0]` wildcard prefix matcher (`win32*`, `pywin*`, `comtypes*`, `clr*`, `wmi*`, `ctypes`, `socket`, `ssl`) + `sys.path` stripping + Environment Variable Sanitization (0 credentials in memory).<br>**Kernel-Level Roadmap (AppContainer Ready)**: `CreateAppContainerProfile` API verified for non-admin execution. ## 2. In-Process Python Defense-in-Depth

Untrusted code generated by AI agents runs within an isolated worker with:
1. **Two-Tier `sys.modules` Cache Poisoning**: Overwrites all pre-cached modules matching network, dynamic FFI, COM automation, and Windows reflection prefixes (`win32*`, `pywin*`, `comtypes`, `ctypes`, `socket`, `ssl`).
2. **`sys.meta_path[0]` Interceptor**: Preempts import lookups after cache clearing (`del sys.modules[...]`) and raises `PermissionError`.
3. **`sys.path` Sanitization**: Strips project workspace roots from `sys.path` to prevent importing internal modules (e.g. `jarvis.sandbox.security`).
4. **Output Stream Capping**: Limits `sys.stdout` to 1MB to prevent parent memory exhaustion attacks.
